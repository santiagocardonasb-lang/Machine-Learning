Machine Learning

El Machine Learning es una rama de la inteligencia artificial que permite a las computadoras aprender patrones a partir de datos, sin ser programadas explícitamente para cada tarea.

Tipos de Machine Learning

1. Aprendizaje supervisado

Se entrena con datos etiquetados: cada entrada tiene su respuesta correcta. Ejemplos: clasificar correos como spam, predecir el precio de una casa.

2. Aprendizaje no supervisado

Los datos no tienen etiquetas. El modelo busca estructuras ocultas por su cuenta. Ejemplos: segmentar clientes, agrupar documentos por tema.

3. Aprendizaje por refuerzo

Un agente aprende probando acciones y recibiendo recompensas o castigos. Ejemplos: robots que aprenden a caminar, motores de juego como AlphaGo.
