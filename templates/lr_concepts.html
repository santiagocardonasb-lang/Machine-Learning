Linear Regression Concepts

What is Linear Regression?

A supervised learning algorithm that describes the relationship between two quantitative variables with a straight line. Once the line is found, it can be used to estimate the value of one variable from the other.

What problems does it solve?

Problems where the answer is a number, not a category: estimating sales, prices, consumption, temperatures or delivery times. If the answer were a category, the problem would call for classification instead.

The two variables

X

Independent variable

The input. The value that is known and that is used to make the prediction. It is also called the predictor. In this application it is the advertising investment.

Y

Dependent variable

The output. The value the model tries to predict, and whose behaviour depends on X. In this application it is the number of units sold.

Relationship between the variables

Linear Regression assumes the relationship is linear: when X grows, Y grows or shrinks at a roughly constant rate. That relationship can be:

  • Positive: more advertising investment, more sales.
  • Negative: a higher price, fewer units sold.
  • Non-existent: the points show no pattern, and a straight line explains nothing.

The regression line

The straight line that passes as close as possible to every observed point. The algorithm finds it by minimizing the sum of the squared distances between each real point and the line. Its equation is:

Y = a + b · X

  • a - the intercept. The value of Y when X is zero: where the line crosses the vertical axis.
  • b - the slope. How much Y changes for every unit that X increases. It is the steepness of the line.

Prediction

Once the line is known, predicting means replacing X in the equation with a new value and reading the Y that comes out. The result is an estimate, not a certainty: the real points lie around the line, not exactly on it.

A simple example

A shop records how many ice creams it sells depending on the temperature of the day:

Temperature (°C) - X Ice creams sold - Y
2040
2458
2879
32101

Every extra degree adds roughly five ice creams, so the fitted line is close to Y = -62 + 5.1 · X. For a day of 30 °C the model predicts about 91 ice creams - a value that was never in the table, but that follows from the pattern the data shows.
