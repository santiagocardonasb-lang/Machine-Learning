Perceptron Application

Classifying whether an advertising campaign was profitable.

1. Problem context

The marketing team runs several advertising campaigns a year, each with its own budget, duration and mix of channels. Some recover the investment and some do not, and today that is only known once the campaign is over. The goal is to classify a campaign before launching it, so the plan can be adjusted while there is still time.

5. The model

Implemented with Perceptron from scikit-learn, inside a Pipeline that first applies a StandardScaler.

The scaling is not optional here. The three variables live on very different ranges: the budget reaches 40, the duration reaches 60 and the channels only reach 6. The Perceptron adjusts weights proportional to the magnitude of each input, so without scaling the duration would dominate the decision just for having larger numbers. The Pipeline also guarantees that the scaler is fitted only with the training data and that any value typed in the form receives the same transformation.

This model does not produce probabilities. Unlike Logistic Regression, the Perceptron applies a step function and answers 0 or 1 with no middle ground, so there is no confidence value to display.
