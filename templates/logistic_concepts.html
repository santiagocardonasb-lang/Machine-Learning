Logistic Regression Concepts

The concepts needed to understand how the algorithm works before reaching its practical implementation.

What is Logistic Regression?

A supervised learning algorithm that estimates the probability that an observation belongs to one of two classes. Despite its name, it does not predict a number: it predicts a category.

Why is it a classification algorithm?

Because its final answer is a class, not a quantity. It calculates a probability between 0 and 1 and then compares it against a threshold to decide which of the two classes to assign. The number is only an intermediate step.

What is binary classification?

A classification problem with exactly two possible outcomes. Every observation belongs to one class or the other, never to both and never to a third. Typical examples are spam or not spam, fraud or legitimate, and the case implemented in this application: the monthly sales goal was reached or it was not.

The variables

X

Independent variable

The input the model uses to decide. In this application it is the monthly advertising investment, measured in millions of COP.

Y

Dependent or target variable

The class the model tries to assign. Here it is whether the month reached its sales goal. It only takes the values 0 and 1.

0 / 1

Classes or labels

The two possible values of the target variable. In this application, 0 means the goal was not reached and 1 means it was.

Probability of belonging to a class

The model does not answer yes or no straight away. First it calculates how likely it is that the observation belongs to class 1, as a value between 0 and 1. That probability comes from the sigmoid function, an S-shaped curve that squeezes any number into that range.

A month with an investment of 40 million might get a probability of 0.95, and one with 5 million a probability of 0.03. The closer to the middle, the less certain the model is.

Classification threshold

The value that separates one class from the other. By default it is 0.5: if the probability reaches it, the model answers class 1, otherwise class 0.

The threshold can be moved when one mistake costs more than the other. Raising it makes the model more demanding before announcing that the goal was reached, which reduces false positives but increases false negatives.

Linear Regression compared with Logistic Regression

This application implements both algorithms over the same phenomenon, which makes the difference easy to see: one predicts how many units are sold, the other classifies whether the goal was met.

Linear Regression Logistic Regression
Type of problem Regression Classification
What it answers A number A class
Range of the answer Any value Only 0 or 1
Shape of the fit A straight line An S-shaped curve, the sigmoid
How it is evaluated R squared Accuracy, precision, recall and F1
