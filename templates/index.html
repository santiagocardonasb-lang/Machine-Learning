Machine Learning

Machine Learning is a branch of artificial inteligence that allows computers learn patterns througt data, without being programed explicit for every task.

Machine learnig types

1. Supervised Learn

It is trained using label data: each input has their correct answer Example: classify mails like spam, predict the price of a house.

2. Unsupervised Learn

The data dont have labels. The model looking for hidden structures on their own. Example: segment clients, group documents by theme.

3. Effort-based learning

An agent learns by trying out actions and receiving rewards or punishments. Ejemplos: robots que aprenden a caminar, motores de juego como AlphaGo.
