Machine Learning Concepts

What is Machine Learning?

Machine Learning is a branch of artificial intelligence that allows computers to learn patterns from data, without being explicitly programmed for every task. Instead of writing the rules by hand, the programmer supplies examples and the algorithm infers the rules.

What is its main purpose?

To build models that generalize. After learning from past examples, a model can make useful predictions about data it has never seen before. That is the difference between memorizing and learning.

From data to predictions

Step 1

Data

Historical observations of the phenomenon. Each record pairs an input with the result that followed it.

Step 2

Training

The algorithm goes through the data looking for the pattern that best explains the results it observes.

Step 3

Model

The result of the training: a mathematical representation of the pattern that was found.

Step 4

Prediction

The trained model receives a new input and returns the result it expects for it.

Why data is the key ingredient

  • Quantity. A few records only show noise; a large set reveals the underlying pattern.
  • Quality. Wrong or missing values teach the model the wrong lesson. Garbage in, garbage out.
  • Representativeness. The data must cover every situation the model will face in production.
  • Relevance. The variables must have a real connection with what is being predicted.

Everyday examples

Spam filters. The mail client learns which messages users mark as spam and applies that pattern to new mail.
Streaming recommendations. The platform suggests content based on what similar users watched.
House price estimation. From area, location and age, the model estimates a market price.
Voice assistants. Thousands of recordings teach the model to turn audio into text.
Sales forecasting. Exactly what this application does: estimating sales from advertising investment.
