Unsupervised Learning: Concepts

The theory behind K-Means, the algorithm used in this module to group seismic events.

What is unsupervised learning?

A family of algorithms that learn from data with no labels. Nobody tells the model what the correct answer is, so instead of predicting a known value it looks for structure that is already present in the data: groups, anomalies or relationships that were never pointed out.

How it differs from supervised learning

A supervised model is trained with the right answer beside every record, and its accuracy can be measured against it. Here there is no right answer to compare with, so the quality of the result is judged by how compact and separated the groups are, and by whether they mean something in the context of the problem.

Clustering

Clustering is the unsupervised task of dividing a set of records into groups so that the records inside a group resemble each other more than they resemble the records of any other group. What counts as resembling is a distance: two records are similar when the distance between their variables is small.

It is used to segment customers, to detect anomalies, to organise documents by theme, and, as in this module, to identify populations inside a set of physical measurements.

How K-Means works

K-Means divides the records into k groups, where k is chosen in advance. It repeats two steps until the groups stop changing:

Step 1

Assignment

The distance from every record to each of the k centroids is computed, and the record joins the group of the nearest one.

Step 2

Update

Each centroid moves to the average position of the records that were assigned to it.

Moving the centroids changes which one is nearest for some records, so the assignment is done again, and the cycle repeats. It stops when no record changes group, which means the centroids no longer move.

The centroid

The centroid is the centre of mass of a cluster: the average of the coordinates of all its members. It is important to understand that it is not one of the records. It is a computed point, and it can sit in a position where no real observation exists.

Its coordinates describe the typical member of the group, which is what makes each cluster interpretable. A centroid at magnitude 4.8 and depth 450 km describes a deep, energetic earthquake even if no single event has exactly those two values.

Euclidean distance

The distance used to decide which centroid is nearest. For two variables it is the straight line between the two points:

d = √( (x₁ - c₁)² + (x₂ - c₂)² )

Because it adds the differences of both variables without weighting them, the variable with the largest range dominates the result. That is why the data has to be standardised before clustering, and it is documented as a preprocessing step in the Application page.

Limitations

Limitation What it means in practice
k is chosen by the user The algorithm does not discover how many groups there are. It has to be decided beforehand, and justified with a measure such as the silhouette score.
Sensitive to the starting point Different initial centroids can lead to different results. Running the algorithm several times and keeping the best one reduces the risk.
Sensitive to the scale Without standardising, the variable with the widest range decides every assignment on its own.
Assumes round groups It looks for roughly spherical clusters of similar size. It performs poorly on elongated or nested shapes.
