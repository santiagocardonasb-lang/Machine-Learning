Perceptron Concepts

The Perceptron is the classification algorithm assigned to this group. It is the oldest artificial neuron and the foundation of modern neural networks.

Definition

A linear classifier proposed by Frank Rosenblatt in 1958. It receives several numeric inputs, multiplies each one by a weight, adds the results and decides a class depending on whether that sum passes a threshold. It is the simplest model that can be called a neural network: a single neuron.

How it works

It starts with random weights and goes through the training examples one by one. Every time it gets one wrong, it adjusts the weights slightly in the direction that would have produced the right answer. Repeating this over the whole dataset moves the separating boundary until it leaves each class on its own side.

The decision it makes

For a campaign with a budget, a duration and a number of channels, the neuron computes:

sum = w1 · budget + w2 · duration + w3 · channels + b

If the sum is positive it answers class 1, otherwise class 0. The weights w1, w2 and w3 are what the algorithm learns: they measure how much each variable pushes the campaign towards being profitable.

Characteristics, advantages and limitations

Main characteristics

  • It is a supervised, linear and binary classifier.
  • It learns online: it corrects itself example by example.
  • It answers with a class, never with a probability.
  • It needs the variables on a comparable scale.

Advantages

  • Very fast to train, even with many records.
  • Uses little memory: it only stores one weight per variable.
  • Easy to interpret, since each weight shows the influence of a variable.
  • Can keep learning as new data arrives, without retraining from scratch.

Limitations

  • Only separates classes that a straight boundary can divide.
  • If the classes are not linearly separable, it never converges.
  • It gives no probability, so there is no measure of confidence.
  • It is sensitive to the scale and to the order of the examples.

Problems it can solve

Binary classification problems where the two groups can be separated by a straight boundary: filtering spam from legitimate mail, telling apart defective and correct pieces on a production line, deciding whether a transaction deserves review, or the case implemented here, separating profitable campaigns from unprofitable ones. For problems where the boundary is curved, the Perceptron falls short and a multi-layer network or another algorithm is needed.

A real classification problem

A factory inspects bottles at the end of the line. For every bottle it measures the weight, the height and the thickness of the glass, and needs to decide whether it passes quality control or goes to the rejection bin. The three measurements are numeric, the answer is binary, and correct bottles cluster around their nominal values while defective ones drift away from them. A Perceptron learns that boundary in seconds and classifies every new bottle at the speed the line requires.
