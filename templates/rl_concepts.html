Reinforcement Learning

The foundations of the application, explained with our 10 × 10 environment: an agent that learns to go from A to T while avoiding walls and danger zones.

1. What is Reinforcement Learning?

It is the type of Machine Learning in which an agent learns by interacting with an environment. Nobody gives it the correct answer: it tries actions, receives a numerical reward after each one and, over many attempts, learns a policy that maximises the expected return.

Type Learns from Example
Supervised Examples with a known answer Classifying emails
Unsupervised Patterns in data without labels Grouping customers
Reinforcement Interaction and rewards, one decision after another A robot finding the exit of a maze

3. The elements of the problem

Agent

The one that makes decisions and learns from the rewards it receives.

Here: the virtual robot that starts at A.

Environment

Everything outside the agent. It receives the action and returns the next state and a reward.

Here: the 10 × 10 grid with its 20 walls, 10 danger zones and the movement rules.

State

The situation of the agent at a given moment.

Here: its current (row, column), from (0, 0) at A to (9, 9) at T.

Action

What the agent can do in each state.

Here: Up, Down, Left and Right. Each one changes the row or the column by one.

Reward

The number the environment returns after each action. It tells the agent how good the action was.

Here: +50 for reaching T and −1 for every normal move.

Penalty

A negative reward that discourages a behaviour.

Here: −3 for trying to leave the grid, −5 for hitting a wall and −15 for entering a danger zone.

Policy

The rule that decides which action to take in each state. It is what the agent learns.

Here: in each cell, the action with the highest Q-value.

4. Step, episode and experience

Concept Definition In our environment
Step One action: from a state s, the agent takes an action a, receives a reward r and reaches a state s′ Moving Down from (0, 0) to (1, 0) and receiving −1
Episode A complete attempt, from the start until the goal or until the step limit From A until T, or until 200 steps
Experience The tuple (s, a, r, s′) of one step, plus a signal saying whether the episode ended ((0, 0), Down, −1, (1, 0), not ended)

5. Exploration and exploitation

Exploration

Choosing a random action to discover the environment. It is how the agent finds out where the walls, the danger zones and the target are.

Exploitation

Choosing the action with the highest estimated Q-value. It is how the agent uses what it has already learned.

Epsilon-greedy strategy. With probability ε the agent explores and with probability 1 − ε it exploits. Our agent starts with ε = 1.0, so it explores 100 % of the time, and ε is multiplied by 0.99 after every episode until it reaches 0.05. It explores when it knows nothing and exploits when it has learned, keeping 5 % exploration until the end.

6. Rewards, values and Q-Learning

The result of a single transition. A normal move gives −1, entering a danger zone gives −15 and reaching T gives +50.

The sum of the rewards obtained from a moment onwards, each one discounted by γ: G = r₁ + γ·r₂ + γ²·r₃ + … The agent does not maximise the next reward, it maximises the return. That is why it accepts −1 per move to reach the +50 at the end.

A value between 0 and 1 that sets how much the future weighs. We use γ = 0.95: the +50 of T, received 20 steps later, is worth 50 × 0.95²⁰ ≈ 17.9 today. A shorter route therefore has a higher return.

The expected return from a state when the policy is followed. A cell next to T has a high V(s); a cell surrounded by walls and danger zones has a low one.

The expected return after taking action a in state s and then following the policy. Every cell has four Q-values, one per action, and the agent picks the highest one.

The algorithm that learns Q(s, a) from experience. After each transition it builds a target and moves the Q-value towards it:

target = r + γ · max Q(s′, a′)    Q(s, a) ← Q(s, a) + α · (target − Q(s, a))

When the agent reaches T there is no future, so the target is only the reward. Example with α = 0.1: moving Right from (9, 8) to T gives a target of 50, so that Q-value goes from 0 to 5. Later, moving Right from (9, 7) to (9, 8) gives a target of −1 + 0.95 × 5 = 3.75. This is how the value of the goal travels back along the route.

How scikit-learn fits in

An SGDRegressor estimates Q(s, a). Each state-action pair is encoded as a one-hot vector of 400 positions (100 cells × 4 actions), so every weight of the model is the Q-value of one pair. predict() estimates the Q-values and partial_fit() updates them with the observed transitions, without restarting the model. Because the environment is larger than the one used in class, the model is updated once per episode with all the transitions of that episode.
