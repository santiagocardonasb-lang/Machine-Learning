Variable Unit Meaning
magnitude Richter scale The energy released by the earthquake. The scale is logarithmic, so one extra unit means about thirty times more energy.

4. Variance within the clusters

The sum of the squared distances from every event to the centroid of its own cluster. It measures how compact the groups are: the smaller it gets, the tighter the grouping.

{% for iteration in manual.iterations %} {% for value in iteration.variance_per_cluster %} {% endfor %} {% endfor %}
Iteration Cluster 0 Cluster 1 Cluster 2 Total
{{ iteration.number }}{{ value }} {{ iteration.variance_total }}

The variance falls sharply between the first and the second iteration and then barely changes. That is what convergence looks like: the first pass corrects the poor initial positions, and from there the centroids only make small adjustments. The distance moved by the centroids tells the same story, dropping to zero by the third iteration.

5. Final result

Cluster Centroid Characteristics
0 {{ manual.final_centroids[0][0] }} · {{ manual.final_centroids[0][1] }} km Shallow and low magnitude events. The most numerous group, consistent with the crustal seismicity of the fault systems.
1 {{ manual.final_centroids[1][0] }} · {{ manual.final_centroids[1][1] }} km Intermediate depth and moderate magnitude, around 150 km. Matches the behaviour of the Bucaramanga seismic nest.
2 {{ manual.final_centroids[2][0] }} · {{ manual.final_centroids[2][1] }} km Deep and energetic events. The smallest group: at that depth only the larger earthquakes are detected.

The three groups the algorithm found are not an artefact of the method. They correspond to seismic populations that are documented independently, which is the strongest evidence that the clustering is meaningful and not just a partition of the plane.
